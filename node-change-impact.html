⚠️ Честная интерпретация (важно)

Реальный прирост — агрегат ×3.2–4.5, а НЕ per-index ×7–12. Большие per-index числа — это перераспределение контеншна, не ускорение железа:

  • На sharm один индекс xtz_deposit съедал 48% всего loop'а (2 212 из 4 571), остальные голодали.
  • На новой ноде работа размазалась ⇒ «×12 у tezos_claim» = «перестал голодать», не «×12 быстрее».
  • tezos_deposit_operations (~375/мин) остаётся самым медленным полюсом и на новой ноде.

Почему ×3–4.5 — это НЕ single-core clock

Clock между любыми двумя машинами ≈ ×1.5–2. ×3–4.5 требует другого механизма. Датасорс исключён: сырой архив Subsquid отдаёт 4–5.3 млн уровней/мин (реплицировал точный iter_transactions) — индексер утилизирует ~0.1%. Значит затык in-process, и его усилила старая нода. Кандидаты (не подтверждены):

кандидат CPU-контеншн на старой ноде

Event loop = ≤1 ядро; на забитой sharm CFS отдавал долю ядра. Не виден как steal (=0) или iowait.

кандидат Латентность fsync БД

iowait≈0 = диск не насыщен по bandwidth, но НЕ про латентность одного коммита. dipdup await-ит коммиты последовательно ⇒ медленный fsync блокирует loop.

кандидат Memory-pressure / swap

Старая нода под нехваткой RAM ⇒ своп индексера/постгреса. Не проверено.

конфаунд Рестарт

Новая нода = ещё и свежий процесс. «Нода vs деградировавший процесс» этим переездом НЕ разделить.

Что меряли по нодам (Prometheus, снимок)

  • steal ≈ 0 везде → не гипервизор-steal.
  • iowait ≈ 0–2% везде → ни одна нода не упёрта в bandwidth диска.
  • нет cgroup CPU-cap (cpu_quota/cfs_throttled отсутствуют) → «тротлинг» не от лимита.
  • Per-container CPU из этого Grafana не достать (cAdvisor без swarm-лейблов) → нужен docker stats на ноде.

Как доразделить БД-ресурс vs индексер-ресурс

  1. CPU% контейнера индексера под синком (docker stats): ~100% ядра = compute/matcher-bound; низкий CPU при медленном = ждёт коммиты БД (DB-latency-bound).
  2. Postgres: pg_stat_database.blk_write_time + commit-rate; много IO/Lock-wait → БД.
  3. Снять конфаунд рестарта: перезапустить процесс БЕЗ переезда — если тоже ускоряет, дело не в ноде.
